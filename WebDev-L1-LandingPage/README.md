# NOVA — Modern Productivity Landing Page

A responsive and visually polished landing page created as part of the **OASIS Infobyte Web Development & Designing Internship — Level 1 Task 1**.

NOVA is a fictional productivity platform designed to help users organize their work, maintain focus, and track their progress.

## 🎨 Design

The website uses a minimalist visual style with a neutral colour palette, strong typography, rounded cards, and subtle interactions.

The design was created to keep the interface simple while maintaining a modern SaaS/product feel.

## 📱 Responsive Design

The landing page has been designed to work across different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile

CSS media queries are used to adapt the layout for smaller screens.
